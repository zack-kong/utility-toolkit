# Utility Toolkit

A collection of small, local-first utilities.

## Tools

| Tool | Description | Platform |
| --- | --- | --- |
| [Subtitles](subtitles/README.md) | Local bilingual captions for the active Chrome video tab | Windows, Chrome 116+, NVIDIA CUDA |

The `subtitles/` directory contains its own installation, usage, privacy, and third-party notices. Model weights and native runtime binaries are downloaded separately and are not part of this repository.
