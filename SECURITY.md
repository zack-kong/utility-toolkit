# Security

This is a development prototype, not a security-audited product. The subtitles service listens on `127.0.0.1` and requires a locally generated token. Keep the token and `.local-data/` private. Do not expose port 8765 or 8766 to the network, and do not upload logs, captured audio, or transcripts when reporting an issue.

For a suspected vulnerability, use GitHub's private vulnerability reporting if it is enabled for this repository; otherwise contact the repository maintainer privately through their GitHub profile. Do not include exploit details or tokens in a public issue. Non-sensitive bugs can be filed as ordinary issues.
